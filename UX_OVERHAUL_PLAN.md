# TubeVault UX Overhaul - Shipped History

Status: **shipped**.

This file summarizes the UX overhaul completed during the June 2026 review cycle.
It is retained as historical product context rather than a list of current tasks.
See [README.md](README.md) for current features, product behavior, and backlog.

## Shipped Work

- Removed the obsolete Support tab and kept the options navigation focused on Downloads, Settings, Status, and Setup.
- Added completion notifications and optional folder opening for single downloads.
- Added English subtitle and automatic-caption downloads with SRT conversion.
- Replaced channel count text parsing with editable numeric chips.
- Moved history export into Downloads and added an on-brand clear-history confirmation.
- Enlarged history rows, controls, Setup content, and the GitHub setup link.
- Reworked batch selection with virtualized thumbnail rows and progressive bounded probing.
- Added per-video expected size, duration, views, and duplicate indicators.
- Widened the batch dialog and added a shared component summary.
- Moved Cancel to the left and added download icons to confirmation actions.
- Added popup recent results, dedicated Settings and History buttons, branding, and footer version display.
- Added options deep-linking from the popup.
- Separated default formats and quality from default component preselection.
- Added cached diagnostics with silent refresh and a last-checked indicator.
- Added SponsorBlock modes for chapter marking and explicit segment removal.
- Added optional concurrent fragments for faster individual media downloads.
- Added local history retention, batch summaries, and strictly serial queue recovery.
